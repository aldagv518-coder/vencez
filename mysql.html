2. Base de Datos: MySQL

Ejemplos de sintaxis SQL para la gestión de bases de datos y tablas. Se incluyen las operaciones básicas (CRUD) y comandos de visualización.

1. Crear Base de Datos (Create DB)

CREATE DATABASE mi_proyecto;

2. Crear Tablas (Create Table)

CREATE TABLE alumnos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(50) NOT NULL,
    correo VARCHAR(100)
);

3. Mostrar Tablas (Show)

Muestra las tablas existentes en la base de datos actual.

SHOW TABLES;

Resultado simulado:

Tables_in_mi_proyecto
alumnos

4. Insertar Registros (Insert Into)

INSERT INTO alumnos (nombre, correo) 
VALUES ('Ana Lopez', 'ana@ejemplo.com');

Resultado simulado: 1 fila insertada correctamente.

5. Consultas (Select)

SELECT * FROM alumnos;

Resultado simulado de la consulta:

id nombre correo
1 Ana Lopez ana@ejemplo.com

6. Actualizar Datos (Update)

Modifica el correo del alumno con ID 1.

UPDATE alumnos 
SET correo = 'ana.nuevo@ejemplo.com' 
WHERE id = 1;

Resultado simulado de la actualización:

id nombre correo
1 Ana Lopez ana.nuevo@ejemplo.com

7. Eliminar Registros (Delete)

Elimina al alumno con ID 1.

DELETE FROM alumnos 
WHERE id = 1;

Resultado simulado de la eliminación: 1 fila eliminada. La tabla queda vacía.

id nombre correo
No hay registros
